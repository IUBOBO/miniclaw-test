# V0.3 科研材料补充与保存规范

适用目录：`E:/Agent/miniclaw-data`。当前功能版本仍为 V0.2.1；本轮完成材料层，不代表科研工具链已实现，也不提升 `LOCAL_VERSION`。

## 一、目标与证据边界

本轮核验现有材料是否能支撑论文、项目和简历主张，不以重新训练或完整复现实验为目标。证据优先级固定为：

1. **BDGI-Net 论文**：数据集规模、最终指标、消融结果和复杂度的最终来源。
2. **源码**：证明 GMRM、ETA、TAB、双分支解码、损失函数和评价算法真实实现。
3. **保存预测与标签**：证明存在可核对的掩码结果，用于单图案例说明。
4. **交接文档**：补充目录、入口和历史背景，不覆盖论文结论。

最终性能引用论文；具体样例引用保存预测、标签和对应评测口径。两类数值必须分开记录。

## 五、指标口径

| 文件 | 对应证据 | 定义与用途 |
|---|---|---|
| `METRIC-PAPER.yaml` | 论文表格与公式 | 简历、项目介绍和论文结论的唯一最终指标来源 |
| `METRIC-PIXEL-MASK.yaml` | `mask_ARF.py` | Precision、Recall、F1、IoU、Accuracy；阈值 127；逐图计算后平均 |
| `METRIC-OBJECT-MASK.yaml` | `mask_eval.py` | GOC、GUC、GTC；预测阈值 205；连通域匹配并按预测地块面积加权 |

两份脚本负责不同指标，不属于评测冲突。IEVS 只用于交互式单图检查，不作为论文最终结果来源。

## 六、不再作为缺口

- 数据增强前后数量差异。
- 历史训练/验证/测试划分身份。
- 最终权重与训练日志绑定。
- 缺失的训练配置和训练环境。
- 山东、四川边界预测及 Boundary-F1。
- TFNet 源码、日志、配置和本地材料。
- 数据取得方式、授权和许可元数据。
- 论文指标重新复现实验。
- SD/SC 保存预测复现论文表格。

保存预测生成参数不能确认时保留 `unknown`。它可证明已有预测能够核对，但不能证明训练复现。
