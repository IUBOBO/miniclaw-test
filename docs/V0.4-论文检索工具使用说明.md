# V0.4 论文检索工具使用说明

本阶段新增只读 `research_paper_search`，在现有 MiniClaw 聊天页中检索科研工作区已经登记且可提取正文的 PDF。当前不新增独立科研页面。

## 一、工具输入

| 参数 | 必填 | 限制 | 说明 |
|---|---|---|---|
| `query` | 是 | 2–200 字符 | 关键词或短语；中英文均可，模块缩写最稳定 |
| `paper_id` | 否 | 最长 100 字符 | 不填时使用 `research-workspace.json` 的 `default_paper_id` |
| `max_results` | 否 | 1–10，默认 5 | 限制返回的页级证据数量 |

工具只读取工作区内的论文元数据和 PDF，不修改论文、manifest 或样本。

## 二、输出与证据边界

工具返回：

- `status`：`ok`、`no_matches` 或 `error`。
- 当前 `workspaceId` 和 `snapshotId`。
- 实际检索的论文和页数。
- 每条结果的论文 ID、标题、PDF 页码、匹配词、有限长度摘录、相对路径和 SHA-256。
- 解析器缺失、论文缺失、哈希变化或路径越界等结构化问题。

没有匹配时返回 `no_matches` 和空结果，不生成替代事实。输出不包含宿主机绝对路径、SSH 地址或密钥。

## 五、当前限制

- 使用 `pdftotext -layout` 提取已有文字层，不包含 OCR。
- 多栏论文的文本阅读顺序可能交错；页码与原始 PDF 保持一致，引用前应结合页码人工核对。
- 当前是关键词与短语检索，不是向量检索或语义 RAG。
- 当前只登记了 `PAPER-BDGI` 元数据；其他 PDF 需要先补论文元数据才能通过工具检索。
- 本阶段不实现 Memory、代码定位、配置比较或日志分析。
