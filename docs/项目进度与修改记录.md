## 完成一项推进一项

- 每完成一项先验收，再更新对应行的状态、日期、实际版本和证据位置；未通过验收不标为已完成。
- 部分完成写清已做内容与剩余工作；材料收到但未核对时写“已收到，待核对”。
- 每次记录本次完成什么、如何验证、下一步做什么；保留历史，不覆盖原有验收结果。
- 功能阶段使用 V0.1 → V0.2 → V0.3，同阶段小修复使用 V0.1.1，并同步 LOCAL_VERSION。未来版本是路线，不是已经实现的能力。
- 单纯整理文档不提升功能版本。本次版本仍为 V0.1 / 0.1.0。
- 基座构建、Mock 与单元测试、真实模型调用、科研任务评测分别记录，不互相替代。密钥和密码不写入本文件或 Git。
