## V0.2 开发中 — 2026-09-18 OpenAI-compatible Provider 协议接入

- 目标：在保留原有 Anthropic Compatible Provider 的基础上，为第三方模型服务增加 OpenAI Compatible 协议选择，不将模型协议写死为 Anthropic Messages。
- Runner 改造：新增 `anthropic-messages` 与 `openai-completions` 两种 Provider API 协议，并将协议信息沿 `provider-runtime -> RuntimeSessionOptions -> PiRuntimeAdapter -> resolvePiProvider -> ModelRuntime.registerProvider` 传递。
- Provider 配置：后端 Provider 数据结构新增 `apiProtocol`，旧配置缺少该字段时默认回退到 `anthropic-messages`，保持向后兼容。
- 环境注入：新增 `MINICLAW_PROVIDER_API`，Provider 配置会在启动 Agent Runner 时注入对应协议，避免由自定义环境变量覆盖系统协议选择。
- API 层：Provider 创建和修改 Schema 支持 `apiProtocol`；修改协议时视为运行时协议级变更，并使相关旧 Session 失效，避免旧协议状态与新 Provider 配置混用。
- 前端：第三方模型配置页面新增 `Anthropic Compatible` / `OpenAI Compatible` 选择；OpenAI Compatible 模式提示使用 OpenAI Chat Completions 兼容 Base URL。
